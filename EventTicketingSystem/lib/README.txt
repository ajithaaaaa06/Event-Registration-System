OPTIONAL - only needed if you want to use MySQL.

1. Download "MySQL Connector/J" (choose "Platform Independent", ZIP) from:
   https://dev.mysql.com/downloads/connector/j/
2. Unzip it and copy the file  mysql-connector-j-8.x.x.jar  into THIS folder (lib/).
3. Put your MySQL password in config.properties and restart the app.

Without the jar the app still opens, in offline mode, with data saved in data/events.dat.
